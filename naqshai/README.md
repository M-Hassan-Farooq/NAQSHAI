# NAQSHAI — application directory

This folder contains the **Next.js application source** (App Router).

👉 **Full project documentation lives in the repository root:** [`../README.md`](../README.md)

## Quick start

```bash
npm install
npm run dev        # http://localhost:3000
```

Copy `.env.example` → `.env.local` and fill in your keys first. See the root
[README](../README.md) for environment setup, database migrations, the API
reference, architecture, security model, and deployment guides.
